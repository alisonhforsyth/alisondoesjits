# Alison Does Jits — Growth Lab

A lightweight creator analytics dashboard for tracking Instagram and TikTok growth, content performance, and projected audience trends.

## Current features

- Track Instagram and TikTok follower snapshots
- View recent follower velocity and growth trend
- Add post-level reach, views, sends, profile visits, and follows
- Review a compounding-growth scorecard
- Compare recent content performance
- Forecast followers 30, 60, and 90 days forward
- Load demo data to explore the app immediately
- Export snapshots as CSV
- Store data locally in the browser

## Privacy

This prototype stores entered analytics in your browser with localStorage. The repository does not contain your private analytics data.
